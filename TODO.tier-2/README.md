## Cross-cutting theme

Most Tier 2 items are about depth — taking existing functionality and
making it production-grade for specific use cases. Mail merge targets
ops teams. Citations target academia. Plugin system targets
extensibility. Lint targets compliance. Together they make uniword
the right answer for "we need to process documents at scale, with
rules."
