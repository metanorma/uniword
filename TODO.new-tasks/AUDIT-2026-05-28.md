# Architecture Audit: fix/deterministic-id-generation

## Scope
125 files changed (+5480, -1501 lines). Reconciler split into 8 modules,
builder refactoring, deterministic ID generation, model changes.

## Critical Issues (must fix before merge)

### 1. Run Consolidation Causes Content Loss [017]
`Reconciler::Helpers#consolidate_runs` merges runs with different revision
tracking (rsidR, rsidRPr) because `can_merge?` only checks formatting, not
run-level attributes. Causes 2 round-trip test failures.

### 2. Field Instruction Test Regressions [018]
8 test failures because `fldChar`/`instrText` now correctly map to Run-level
attributes instead of Paragraph-level. Tests need updating for the correct
behavior.

### 3. Forbidden Patterns in Library Code [019]
- `respond_to?` in `document_builder.rb:41` — unnecessary type check
- `public_send` in `chart_builder.rb:270` — should be explicit dispatch
- `public_send` in `run.rb:187-201` — attribute iteration
- `public_send` in `document_differ.rb:443,455,469` — field access
- `send` in `image_enhancements_spec.rb` — testing private methods

## Architectural Issues (DRY violations)

### 4. Duplicate Run Merging Logic [020]
`ParagraphBuilder` and `Reconciler::Helpers` independently implement
`empty_run?`, `text_only_run?`, `rpr_match?`, and merge logic with divergent
completeness. Builder's `text_only_run?` checks 5 element types vs
reconciler's 10.

### 5. Duplicate DEFAULT_TABLE_LOOK [021]
Identical constant and manual property copying in both `TableBuilder` and
`Reconciler::Tables`.

### 6. Duplicate Header/Footer Wiring [023]
`Reconciler::Body` and `PackageSerialization` both implement sectPr
wiring with different strategies (idempotent find_or_create vs always-new).

### 7. Dead Mapping Constants [022]
`DOCUMENT_TO_PACKAGE_MAPPINGS` and `PACKAGE_PART_MAPPINGS` are never used
after the `public_send` elimination. Dead code.

### 8. Page Size Defaults Duplication [026]
US Letter dimensions and default margins hardcoded in both `Reconciler::Body`
and `SectionBuilder`.

### 9. mc:Ignorable Assignment Repetition [027]
Same `Ooxml::Types::McIgnorable.new(EXTENSION_PREFIXES)` pattern repeated 10
times across 3 reconciler modules.

### 10. OOXML String Literal Scattering [024]
Content types, relationship URIs, and part names appear as inline strings
across 9+ files instead of being centralized constants.

## Dead Code

### 11. `valid_document_rel?` Never Called [025]
`PackageStructure#valid_document_rel?` is dead code with a potential bug
(`rel[:target]` instead of `rel.target`).

## What's Good

- Reconciler module split is clean — 8 modules, 0 method name collisions
- No `require_relative` in library code (all autoload)
- No `instance_variable_set/get` found
- Reconciler specs: 87 test cases covering 18 describe blocks
- `IdAllocator` centralizes all ID generation — good OCP design
- `ensure_content_type` helper DRYs part injection in serialization
- Module responsibilities are well-separated (MECE)
- No `double()` in specs
